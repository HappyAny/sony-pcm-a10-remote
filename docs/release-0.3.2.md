# 0.3.2 单文件便携版

运行 **`dist/standalone/PCM-A10.exe`** 即可，只需复制这一个文件。程序约 76 MB，包含 .NET 10.0.14 Windows Desktop Runtime x64 和 Python 3.14.1 控制核心，无需安装 .NET 或 Python。模拟模式可通过 `PCM-A10.exe --demo` 启动。`Launch.cmd` 和源码命令行默认入口均优先选择它。

充电图标代码与 0.3.1 逐字节一致。540×620 的紧凑窗口、合并录音按钮、电池颜色、完整设置和退出释放设备的行为均保留。

采用微软官方的自包含单文件发布，嵌入原生运行库并开启程序集压缩，未启用 WPF 裁剪。[Microsoft 单文件发布说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview) 说明了运行库包含方式及临时解压行为。控制核心作为嵌入资源，仅在运行时解压到当前用户的专属临时目录，通过私有标准输入／输出通信；不监听网络端口。

正常关闭会先释放蓝牙、退出专属后端，再删除其临时目录。异常退出时，Windows Job Object 负责结束所属后端；下次启动会回收已失去所属窗口的临时目录。其他正在运行的窗口持有独占租约，程序不会删除它们的运行目录。.NET 自身的原生运行库缓存由 .NET 管理。

| 原有控制回归 | 58 项自动测试通过；单文件模拟流程覆盖 15 项设置、My Scene、试音、直接增益、四类标记和合并录音按钮 |

| 充电显示 | `BatteryIndicator.cs` 与 0.3.1 发布包内版本完全一致 |

本机已安装 .NET；隔离验证通过移除运行库搜索路径、只复制 EXE 和核对自包含配置来检查打包完整性，未另用干净 Windows 虚拟机。此轮验证均使用模拟器，没有操作已有的真实录音机连接；历史硬件结果与新增功能的实机验证边界继续保留。
