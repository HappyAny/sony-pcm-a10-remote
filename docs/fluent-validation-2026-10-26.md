# PCM-A10 Fluent 0.2.0 验证记录

界面已重写为 C# / WPF 原生应用，使用 .NET 10 官方 Fluent 主题。默认启动脚本与 Python 的默认 GUI 入口均指向此版本。蓝牙控制核心复用 0.1.1 的设备确认逻辑，通过私有 UTF-8 JSON 行与界面通信。

| 验证项 | 结果与边界 |
|---|---|
| Release 构建 | 通过，win-x64，依赖已安装的 .NET 10 Windows Desktop Runtime |
| Python 协议、会话、Windows ABI 与界面通信桥 | 32 项自动测试全部通过 |
| 已打包原生界面与后端集成 | 通过：录音、增益加、标记、暂停、继续、停止；状态由模拟设备返回 |
| 浅色、深色、系统主题切换 | 原生程序内部切换自检通过；深色视觉检查未完成 |
| 实际窗口与鼠标操作 | 已打开原生窗口，检查浅色卡片布局，点击模拟录音按钮并观察计时、双声道电平与操作记录 |
| 窗口布局修正 | 按钮继承官方 Fluent 样式；录音按钮保留红色状态；增加滚动布局、校正电平刻度、菜单向内展开，并调整主题文字对比度；最后一轮小窗口人工检查未完成 |
| 退出行为 | 通信桥自动测试确认断开连接且不发送停止录音命令 |
| 普通 Windows 进程的设备枚举 | 通过，发现 1 个适配器及 1 台已配对 PCM-A10 |
| Fluent 版实机控制 | 未完成。桌面操作被用户按 Esc 停止后，未继续执行设备连接或录音控制 |
| 原有控制核心的实机验证 | 沿用此前已完成的真实录音、暂停、继续、停止、标记、时间、电池和双声道电平记录，见 hardware-test-2026-10-26.md |
| 实机增益调整 | 当前设备设置下被拒绝，保持此前已验证的拒绝检测；未声称成功调整 |

发布程序含私有 Python 后端，不包含 Tcl/Tk 或旧 Tk 可执行程序。发布包附 C# 和 Python 源码、许可证、逐文件 SHA256；打包脚本验证 CRC 并重新计算 ZIP 内各文件 SHA256。Sony APK、反编译材料和原始设备日志不进入发布包。

`fluent-self-test.json` 记录的是模拟器验证，不代表本轮 Fluent 界面已完成全部实机测试。当前未导出或试听录音文件，亦未验证长时间连接。新界面只提供遥控，不提供 USB 或蓝牙实时音频输入。
