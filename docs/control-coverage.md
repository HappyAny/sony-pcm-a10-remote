# PCM-A10 控制功能覆盖表（0.3.0）

本表覆盖 Sony REC Remote 3.5.0 中可确认的 A10 遥控路径。命令和选项根据本地已验签客户端的静态调用链独立实现，并与此台 A10 的真实能力回执核对。它不是 Sony 公开的完整固件协议规范。原始客户端与反编译材料不随本项目分发。

此前实机返回了 21 项能力。15 项普通录音设置、My Scene 保存和试音都有可确认的控制语义；另外 3 项扩展能力仅保留在诊断记录中，没有猜测写入方式。自动标记旧式条目 0504 与新式的 0506/0507 合并呈现，避免重复设置。原始能力数据不含设备标识，见 [能力快照](a10-capabilities-2026-10-26.json) 和自动测试 fixture。

## 录音与标记

| 功能 | 接口与确认 | 界面 |
|---|---|---|
| 录音／继续 | 10 03，读取 0704=3 | 录音页红色按钮 |
| 暂停／待机 | 10 02，读取 0704=2 | 录音页 |
| 停止 | 10 01，读取 0704=1 | 录音页 |
| 试音开始／结束 | 10 06 / 10 07，读取 070E；2 表示进行中 | 录音页；不自行切换输入模式 |
| 增益加／减 | 10 04 / 10 05，检查 16 返回码，再查询 0604 | 电平行 |
| 增益直设 | 15 06 04，值 0–30，设备设置结果与读回值均需确认 | 输入数值后点击“设置” |
| 当前输入切手动 | 根据新读取的 070B，写 0201=8、0202=8 或 0203=4；按设备能力核对 | 明确点击“当前输入切为手动” |
| 普通／重要／问题／新话题 | 11 06 03，类型分别为 1/2/3/4；名称 1–128 UTF-8 字节；解析 12 回执 | 四个独立按钮与自定义名称框 |
| 最近标记 | 13，解析 14 | “读取最近”；显示编号、时间、名称 |
| 文件名 | 33 07 08 09，解析 34；09 为简体中文语言参数 | 录音页状态行与设备详情 |

试音状态 3 表示需要手动灵敏度。程序会提示明确切换，不自动改输入。录音期间不启动试音；试音期间禁止手动调增益和更改录音设置。已确认的录音动作不自动重复发送。

## 录音设置

| 设置 | 项目 | 此台 A10 报告的选项 |
|---|---|---|
| 录音格式 | 0101 | LPCM 96 kHz/24 bit、48 kHz/24 bit、48 kHz/16 bit、44.1 kHz/24 bit、44.1 kHz/16 bit；MP3 320/192/128/48 kbps，48 kbps 为单声道 |
| 场景 | 0403 | 关闭、自动人声、会议、讲座、备忘、采访、乐队、独唱／乐器、My Scene 1/2 |
| 内置麦克风灵敏度 | 0201 | 人声自动、高／中／低人声、高／中／低音乐、手动 |
| 外接麦克风灵敏度 | 0202 | 同上，受当前外部输入连接条件限制 |
| 音频输入灵敏度 | 0203 | 高、低、手动；设备未报告“中”选项 |
| 外部输入类型 | 0301 | 麦克风、音频／Line |
| 录音滤波 | 0401 | 关闭、NCF、LCF |
| 限幅器 | 0402 | 开启／关闭 |
| 预录音 | 0509 | 开启／关闭 |
| VOR | 0502 | 开启／关闭 |
| 同步录音 | 0503 | 开启／关闭 |
| 跨存储器录音 | 0501 | 开启／关闭 |
| 自动标记 | 0507 | 开启／关闭 |
| 自动标记间隔 | 0506 | 5、10、15、30 分钟；依照官方调用顺序先开启 0507 |
| 标记附加时间 | 0505 | 开启／关闭 |
| 保存自定义场景 | 0602 | 保存到 My Scene 1 或 My Scene 2；执行前确认覆盖 |

每项写入都检查 16 设置回执，并用 17/18 读回实际值。0xA1 拒绝不能被之后成功的查询覆盖。0xA0 按原客户端的处理方式允许进入读回验证，只有目标实际值相符才报告完成。My Scene 保存属于动作项，检查设置回执中的目标槽位，不将后续读取当作持久化内容的独立证明。

对场景、输入等会影响其他值的操作，之后重新读取整个设置目录。未提供隐藏的批量写入、自动恢复预设、自动停止当前录音等行为。

代码还支持按设备能力呈现单／双声道、聚焦／宽域、独立低切频率、高信噪比、旧式自动标记和设备峰值保持；此台 A10 的能力回执未提供这些可用控制，因此正常界面不显示。设备峰值清除使用 10 08，读取 35/36 验证可用峰值数据；界面只在设备报告相关能力时提供按钮，不将单纯传输成功表述为峰值已清除。

## 状态信息

已解析电池档位及充电／低电量状态、输入源、录音／待机状态、试音状态、增益、当前录音格式、场景修改标识、录音时间、剩余时间、文件名、预录缓存秒数、睡眠定时器指示和标记回执。支持 11 字节、17 字节电平记录；后一种还提供双声道峰值和峰值过载标志。收到 41 设备通知时，在界面显示提示及编号，供用户与机身屏幕核对。

0102、0103、0204 的能力已捕获，但原客户端没有已确认的设置调用语义。本程序在折叠诊断区记录它们，不将其伪装成可操作控件，也不发送猜测的写入。

## 验证与接口边界

52 项自动测试覆盖实际能力 fixture、完整目录选项、读写读回、拒绝回执、无实际变化、试音状态、显式手动输入、四类 UTF-8 标记、文件名、峰值、原生通信桥及丢失 ACK 行为。打包后的 Fluent 程序完成 15 项设置、My Scene、试音和四类标记的模拟集成自检。

本轮真实蓝牙连接返回 10049，未获得 Sony 控制通道，未执行设置更改；因此新增设置、试音及 My Scene 的实机写入不在本次已验证范围。原有基础录音控制仍保留此前的真实回执记录。图像预览由程序自身的模拟界面渲染生成，带模拟标识，不是新功能实机运行证明。

Sony 明确说明 REC Remote 用于录音遥控，不提供回放、录音监听或文件传输。本项目也没有把该接口包装成实时音频声卡。PCM-A10 的 A2DP 音频输出属于另一种蓝牙用途，不构成本轮 REC Remote 控制接口的音频输入能力。
